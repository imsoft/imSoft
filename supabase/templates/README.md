# Plantillas de correo de Supabase Auth

Generadas con `node --experimental-strip-types scripts/build-auth-emails.mjs`.
Se pegan a mano en Supabase: Authentication > Email Templates.

| Plantilla en Supabase | Asunto | Archivo |
|---|---|---|
| Confirm signup | Confirma tu cuenta en imSoft | `confirmar-registro.html` |
| Invite user | Te invitaron a imSoft | `invitacion.html` |
| Magic Link | Tu enlace para entrar a imSoft | `enlace-magico.html` |
| Change Email Address | Confirma tu nuevo correo en imSoft | `cambio-de-correo.html` |
| Reset Password | Restablece tu contraseña de imSoft | `recuperar-contrasena.html` |
| Reauthentication | Tu código de verificación de imSoft | `reautenticacion.html` |
