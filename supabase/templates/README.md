# Plantillas de correo de Supabase Auth

Generadas con `node --experimental-strip-types scripts/build-auth-emails.mjs`.
Se pegan a mano en Supabase: Authentication > Email Templates.

| Plantilla en Supabase | Asunto | Archivo |
|---|---|---|
| Confirm signup | Confirma tu cuenta en imSoft | `confirm-signup.html` |
| Invite user | Te invitaron a imSoft | `invite.html` |
| Magic Link | Tu enlace para entrar a imSoft | `magic-link.html` |
| Change Email Address | Confirma tu nuevo correo en imSoft | `change-email.html` |
| Reset Password | Restablece tu contraseña de imSoft | `reset-password.html` |
| Reauthentication | Tu código de verificación de imSoft | `reauthentication.html` |
